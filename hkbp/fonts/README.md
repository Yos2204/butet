# Warta fonts

Liberation Sans and Liberation Sans Narrow 1.07 (Red Hat), cut down to Latin characters.
They have the same letter widths as Arial and Arial Narrow, so the Warta Jemaat PDF lines up like the Word file
on phones that do not have the Microsoft fonts. Phones and computers that have Arial / Arial Narrow use those instead.
